ARGO

The helm. Every window steers by one shared feel — mouse, puck, and star.

One ship, many helmsmen

ARGO is the shared feel: one calibration file (~/.config/signature/nav.json) that every Leviathan window steers by. Mouse orbit, zoom, and pan gains; spacemouse signs and sources; the Shift attitude layer — tuned once in any window's NAV panel, honored by all of them. (The buttons still read NAV.)

Each window writes only the keys it owns — a read-modify-write, so one module's tuning never erases another's.
